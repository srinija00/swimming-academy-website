# Certified Swim Coach Website

## Project Overview

A responsive Swimming Academy website developed using HTML, CSS, JavaScript, and Bootstrap.

The website is designed to attract parents and students by showcasing swimming programs, certificates, testimonials, achievements, and training facilities.

## Features

- Responsive Design
- Hero Section
- Training Programs
- About Us
- Certificates Section
- Photo Gallery
- Testimonials
- Contact Form
- Mobile Friendly Interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
